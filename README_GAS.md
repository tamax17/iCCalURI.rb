# 講義室予約管理システム (Google Apps Script版)

画像の大学スケジュール表を参考にした、Google Apps Scriptで作成された講義室予約管理WEBアプリケーションです。

## 特徴

✨ **主な機能**
- 📅 週単位のスケジュール表表示
- 🏫 複数講義室の管理
- ➕ 講義の予約作成・編集・削除
- 🎨 講義タイプ別の色分け表示
- 📱 レスポンシブデザイン
- 🔄 リアルタイム更新
- 💾 Googleスプレッドシートでデータ管理

✅ **利点**
- 🆓 完全無料で利用可能
- 🚀 サーバー不要
- 🔒 Googleアカウントでセキュア
- 📊 スプレッドシートで簡単データ管理
- 🌐 どこからでもアクセス可能

## セットアップ手順

### 1. Google Apps Scriptプロジェクトの作成

1. [Google Apps Script](https://script.google.com/)にアクセス
2. 「新しいプロジェクト」をクリック
3. プロジェクト名を「講義室予約管理システム」に変更

### 2. ファイルの作成

#### 2.1 Code.gs (メインスクリプト)
- `Code.gs`ファイルに`gas/Code.gs`の内容をコピー&ペースト

#### 2.2 index.html (メインページ)
- 「+」ボタンから「HTMLファイル」を選択
- ファイル名を`index`に設定
- `gas/index.html`の内容をコピー&ペースト

#### 2.3 css.html (スタイルシート)
- 「+」ボタンから「HTMLファイル」を選択
- ファイル名を`css`に設定
- `gas/css.html`の内容をコピー&ペースト

#### 2.4 javascript.html (JavaScript)
- 「+」ボタンから「HTMLファイル」を選択
- ファイル名を`javascript`に設定
- `gas/javascript.html`の内容をコピー&ペースト

### 3. スプレッドシートの初期化

1. Google Apps Scriptエディタで`initializeSpreadsheet`関数を実行
2. 初回実行時は権限の承認が必要です
3. 実行ログからスプレッドシートのIDをコピー
4. `Code.gs`の`SPREADSHEET_ID`に貼り付け

```javascript
const SPREADSHEET_ID = 'ここにスプレッドシートIDを貼り付け';
```

### 4. Webアプリとして公開

1. 「デプロイ」→「新しいデプロイ」をクリック
2. 種類を「ウェブアプリ」に選択
3. 設定：
   - **説明**: 講義室予約管理システム
   - **次のユーザーとして実行**: 自分
   - **アクセスできるユーザー**: 組織内の全員（または必要に応じて設定）
4. 「デプロイ」をクリック
5. 生成されたURLでアプリにアクセス可能

## 使用方法

### 基本操作

#### 📅 スケジュール表示
- 週単位でスケジュールを表示
- 「前週」「次週」ボタンで週移動
- 各セルに講義情報が色分けして表示

#### ➕ 予約追加
1. 「予約追加」ボタンまたは空いているセルをクリック
2. フォームに講義情報を入力：
   - **講義室**: プルダウンから選択（必須）
   - **タイトル**: 講義名（必須）
   - **担当者**: 教員名
   - **講義コード**: 講義識別コード
   - **日付**: 開催日（必須）
   - **開始時間**: 開始時刻（必須）
   - **終了時間**: 終了時刻（必須）
   - **色**: 講義タイプによる色分け
   - **説明**: 追加情報
3. 「保存」をクリック

#### ✏️ 予約編集
1. 既存の予約をクリック
2. フォームで情報を編集
3. 「保存」で更新、「削除」で削除

### 色分けシステム

| 色 | 用途 |
|---|---|
| 🔵 青 | 通常講義 |
| 🔴 赤 | 試験 |
| 🟢 緑 | セミナー |
| 🟠 橙 | 会議・その他 |

## データ管理

### スプレッドシート構造

#### 講義室シート
| 列 | 項目 | 説明 |
|---|---|---|
| A | ID | 自動生成される一意識別子 |
| B | 講義室名 | 表示名 |
| C | 収容人数 | 定員 |
| D | 建物 | 所在建物 |
| E | 階 | 所在階数 |
| F | 設備 | 利用可能設備 |

#### 予約シート
| 列 | 項目 | 説明 |
|---|---|---|
| A | ID | 自動生成される一意識別子 |
| B | 講義室ID | 講義室との関連付け |
| C | 講義室名 | キャッシュされた講義室名 |
| D | タイトル | 講義・イベント名 |
| E | 担当者 | 教員・責任者名 |
| F | 講義コード | 識別コード |
| G | 開始時間 | HH:MM形式 |
| H | 終了時間 | HH:MM形式 |
| I | 日付 | YYYY-MM-DD形式 |
| J | 色 | 16進数カラーコード |
| K | 説明 | 追加情報 |
| L | 作成日時 | 自動記録 |

### データのバックアップ

スプレッドシートは自動的にGoogleドライブに保存されます。追加のバックアップが必要な場合：

1. スプレッドシートを開く
2. 「ファイル」→「ダウンロード」→「Excel (.xlsx)」
3. 定期的にローカルにダウンロード

## カスタマイズ

### 講義室の追加・編集
1. スプレッドシートの「講義室」シートを開く
2. 新しい行に講義室情報を追加
3. Webアプリを再読み込み

### 時間帯の変更
`Code.gs`の`generateTimeSlots`関数を編集：

```javascript
function generateTimeSlots() {
  const slots = [];
  for (let hour = 8; hour < 20; hour++) { // 8:00-20:00に変更
    slots.push(`${hour.toString().padStart(2, '0')}:00`);
    slots.push(`${hour.toString().padStart(2, '0')}:30`);
  }
  return slots;
}
```

### 色の追加・変更
`index.html`と`javascript.html`の色オプション部分を編集。

## トラブルシューティング

### よくある問題

#### 「スプレッドシートが見つかりません」エラー
- `SPREADSHEET_ID`が正しく設定されているか確認
- スプレッドシートへのアクセス権限があるか確認

#### 予約が保存されない
- 必須フィールドがすべて入力されているか確認
- 時間の重複がないか確認
- ブラウザのJavaScriptが有効になっているか確認

#### アプリが読み込まれない
- Google Apps Script APIが有効になっているか確認
- ブラウザのポップアップブロッカーを無効化
- Webアプリの公開設定を確認

### デバッグ方法

1. Google Apps Scriptエディタの「実行ログ」を確認
2. ブラウザの開発者ツールでJavaScriptエラーを確認
3. スプレッドシートのデータ形式を確認

## セキュリティ

- アクセス権限を適切に設定
- 組織外からのアクセスが不要な場合は制限
- 定期的にアクセスログを確認
