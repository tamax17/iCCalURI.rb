# 講義室予約管理システム (Google Apps Script版) - 曜日テンプレート対応

画像の大学スケジュール表を参考にした、Google Apps Scriptで作成された講義室予約管理WEBアプリケーションです。

## 🎓 大学の時間割管理に最適

**曜日テンプレート機能** により、大学の実際の運用に合わせた効率的な時間割管理が可能です：

1. **📅 曜日テンプレート作成** - 月〜日の曜日ごとに講義の時間割を作成
2. **📚 学年歴設定** - 学期、休日、試験期間などを設定
3. **🔄 自動展開** - テンプレート × 学年歴で実際の予約を一括生成

## 特徴

✨ **主な機能**
- 📅 **曜日テンプレート管理** - 月〜日の時間割作成
- 📚 **学年歴対応** - 前期/後期、休日、試験期間の設定
- 🔄 **自動予約展開** - テンプレートから実際の予約を一括生成
- 🏫 **複数講義室管理** - 16の講義室を事前設定
- 🎨 **講義タイプ別色分け** - 講義、試験、セミナー、会議
- 📱 **レスポンシブデザイン** - スマートフォンでも利用可能
- 💾 **Googleスプレッドシートでデータ管理**

✅ **利点**
- 🆓 完全無料で利用可能
- 🚀 サーバー不要
- 🔒 Googleアカウントでセキュア
- 📊 スプレッドシートで簡単データ管理
- 🌐 どこからでもアクセス可能
- ⏱️ 一度のテンプレート作成で学期全体の予約が完了

## セットアップ手順

### 1. Google Apps Scriptプロジェクトの作成

1. [Google Apps Script](https://script.google.com/)にアクセス
2. 「新しいプロジェクト」をクリック
3. プロジェクト名を「講義室予約管理システム（曜日テンプレート版）」に変更

### 2. ファイルの作成

#### 2.1 Code.gs (メインスクリプト)
- `Code.gs`ファイルに`gas/Code.gs`の内容をコピー&ペースト

#### 2.2 index.html (メインページ)
- 「+」ボタンから「HTMLファイル」を選択
- ファイル名を`index`に設定
- `gas/index.html`の内容をコピー&ペースト

#### 2.3 css.html (スタイルシート)
- 「+」ボタンから「HTMLファイル」を選択
- ファイル名を`css`に設定
- `gas/css.html`の内容をコピー&ペースト

#### 2.4 javascript.html (JavaScript)
- 「+」ボタンから「HTMLファイル」を選択
- ファイル名を`javascript`に設定
- `gas/javascript.html`の内容をコピー&ペースト

### 3. スプレッドシートの初期化

1. Google Apps Scriptエディタで`initializeSpreadsheet`関数を実行
2. 初回実行時は権限の承認が必要です
3. 実行ログからスプレッドシートのIDをコピー
4. `Code.gs`の`SPREADSHEET_ID`に貼り付け

```javascript
const SPREADSHEET_ID = 'ここにスプレッドシートIDを貼り付け';
```

### 4. Webアプリとして公開

1. 「デプロイ」→「新しいデプロイ」をクリック
2. 種類を「ウェブアプリ」に選択
3. 設定：
   - **説明**: 講義室予約管理システム（曜日テンプレート版）
   - **次のユーザーとして実行**: 自分
   - **アクセスできるユーザー**: 組織内の全員（または必要に応じて設定）
4. 「デプロイ」をクリック
5. 生成されたURLでアプリにアクセス可能

## 使用方法

### 🎯 基本ワークフロー

```
1. 曜日テンプレート作成 → 2. 学年歴設定 → 3. 予約展開 → 4. 運用開始
```

### 📅 ステップ1: 曜日テンプレート作成

#### テンプレート管理モード
1. 「テンプレート管理」タブを選択
2. 曜日フィルターで編集したい曜日を選択（例：月曜日）
3. 「テンプレート追加」ボタンまたは空いているセルをクリック

#### テンプレート入力項目
- **曜日**: 月〜日から選択（必須）
- **講義室**: プルダウンから選択（必須）
- **タイトル**: 講義名（例：データベース設計）（必須）
- **担当者**: 教員名（例：田中太郎）
- **講義コード**: 識別コード（例：CS101）
- **開始時間**: 講義開始時刻（必須）
- **終了時間**: 講義終了時刻（必須）
- **色**: 講義タイプによる色分け
- **説明**: 追加情報

#### テンプレート編集・削除
- 既存のテンプレートをクリックして編集
- 編集モーダルで「削除」ボタンでテンプレート削除

### 📚 ステップ2: 学年歴設定

スプレッドシートの「学年歴」シートで以下を設定：

#### 初期設定済み項目
- **前期**: 4月1日〜9月30日
- **後期**: 10月1日〜3月31日
- **ゴールデンウィーク**: 4月29日〜5月5日（除外）
- **夏季休暇**: 8月1日〜8月31日（除外）
- **冬季休暇**: 12月25日〜1月7日（除外）
- **前期試験**: 7月15日〜7月31日
- **後期試験**: 1月15日〜1月31日

#### カスタマイズ方法
学年歴シートを直接編集して以下を追加・変更：
- 祝日の追加
- 学校行事日の設定
- 集中講義期間の設定
- 補講日の設定

### 🔄 ステップ3: 予約展開

#### 展開実行
1. 「予約展開」ボタンをクリック
2. 期間を指定（例：2024年4月1日〜2024年9月30日）
3. 「展開実行」をクリック

#### 展開結果
- テンプレート × 授業日 = 実際の予約が自動生成
- 休日・祝日は自動的に除外
- 既存の予約は削除されて新しく作成

### 📊 ステップ4: 予約一覧確認

#### 予約一覧モード
1. 「予約一覧」タブを選択
2. 週単位で実際の予約を確認
3. 「前週」「次週」ボタンで週移動

## 運用例

### 🎓 大学での実際の使用例

#### 前期の運用準備（3月）
1. **新年度の講義テンプレート作成**
   - 月曜1限：線形代数（A302）
   - 月曜2限：データベース設計（S207）
   - 火曜1限：プログラミング基礎（A403）
   - ...（全曜日・全時限）

2. **学年歴の確認・更新**
   - 前期期間：4月8日〜7月31日
   - GW休暇：4月29日〜5月5日
   - 前期試験：7月15日〜7月26日

3. **予約展開実行**
   - 期間：2024年4月8日〜2024年7月31日
   - 結果：約400件の予約が自動生成

#### 学期中の運用（4月〜7月）
- 「予約一覧」モードで週単位の確認
- 急な休講・補講は個別に手動調整
- 試験期間は特別スケジュールで運用

#### 後期の準備（9月）
- テンプレートの見直し・更新
- 学年歴の後期設定確認
- 再度予約展開で後期予約を生成

## カスタマイズ

### 講義室の追加・編集
1. スプレッドシートの「講義室」シートを開く
2. 新しい行に講義室情報を追加
3. Webアプリを再読み込み

### 時間帯の変更
`Code.gs`の`generateTimeSlots`関数を編集：

```javascript
function generateTimeSlots() {
  const slots = [];
  for (let hour = 8; hour < 20; hour++) { // 8:00-20:00に変更
    slots.push(`${hour.toString().padStart(2, '0')}:00`);
    slots.push(`${hour.toString().padStart(2, '0')}:30`);
  }
  return slots;
}
```

### 学年歴のカスタマイズ
スプレッドシートの「学年歴」シートで以下を編集：

```
例：祝日の追加
タイプ: 休日
名称: 文化の日
開始日: 2024-11-03
終了日: 2024-11-03
除外フラグ: true
説明: 国民の祝日
```

### 色の追加・変更
`index.html`と`javascript.html`の色オプション部分を編集。

## トラブルシューティング

### よくある問題

#### 「スプレッドシートが見つかりません」エラー
- `SPREADSHEET_ID`が正しく設定されているか確認
- スプレッドシートへのアクセス権限があるか確認

#### テンプレートが保存されない
- 必須フィールド（曜日、講義室、タイトル、時間）が入力されているか確認
- 同じ講義室・曜日・時間帯で重複がないか確認

#### 予約展開がうまくいかない
- テンプレートが作成されているか確認
- 展開期間が正しく設定されているか確認
- 学年歴の除外設定を確認

#### アプリが読み込まれない
- Google Apps Script APIが有効になっているか確認
- ブラウザのポップアップブロッカーを無効化
- Webアプリの公開設定を確認

### デバッグ方法

1. Google Apps Scriptエディタの「実行ログ」を確認
2. ブラウザの開発者ツールでJavaScriptエラーを確認
3. スプレッドシートのデータ形式を確認
4. 各シートにデータが正しく保存されているか確認

## セキュリティ

- アクセス権限を適切に設定
- 組織外からのアクセスが不要な場合は制限
- 定期的にアクセスログを確認
- スプレッドシートの共有設定に注意
