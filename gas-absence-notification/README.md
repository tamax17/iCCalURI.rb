# 授業欠席連絡システム - Google Apps Script

学生が複数の授業を欠席する際に、各担当教員に一括でメール連絡を送信するWebアプリケーションです。

## 機能概要

- **学生向け機能**
  - Webフォームから欠席連絡を入力
  - 複数科目の一括選択
  - 各担当教員への自動メール送信

- **管理者向け機能**
  - Googleスプレッドシートでの授業情報管理
  - 欠席記録の自動保存・管理
  - メール送信履歴の確認

## システム構成

### ファイル構成
```
gas-absence-notification/
├── Code.gs           # メインスクリプト
├── form.html         # 学生用入力フォーム
├── appsscript.json   # GASプロジェクト設定
└── README.md         # このファイル
```

### データ構造

#### 授業情報シート (`授業情報`)
| 列 | 項目名 | 説明 |
|---|---|---|
| A | 授業科目名 | 授業の名称 |
| B | 担当教員名 | 教員の氏名 |
| C | メールアドレス | 教員の連絡先メールアドレス |

#### 欠席情報シート (`欠席情報`)
| 列 | 項目名 | 説明 |
|---|---|---|
| A | 提出日時 | フォーム送信日時 |
| B | 学生番号 | 学生の識別番号 |
| C | 氏名 | 学生の氏名 |
| D | 欠席開始日 | 欠席期間の開始日 |
| E | 欠席終了日 | 欠席期間の終了日 |
| F | 欠席科目 | 欠席する科目（複数の場合はカンマ区切り） |

## セットアップ手順

### 1. Google Apps Scriptプロジェクトの作成

1. [Google Apps Script](https://script.google.com/) にアクセス
2. 「新しいプロジェクト」をクリック
3. プロジェクト名を「授業欠席連絡システム」に変更

### 2. ファイルのアップロード

1. `Code.gs`の内容を、デフォルトの`Code.gs`にコピー＆ペースト
2. `+`ボタン → `HTMLファイル`をクリックし、「form」という名前でHTMLファイルを作成
3. `form.html`の内容を上記ファイルにコピー＆ペースト
4. 歯車アイコン → `appsscript.json`の内容を更新

### 3. スプレッドシートの準備

#### 自動作成の場合
1. `initializeSheets()`関数を実行
2. 実行ログに表示されるスプレッドシートIDをコピー
3. `Code.gs`の`SPREADSHEET_ID`をコピーしたIDに変更

#### 手動作成の場合
1. 新しいGoogleスプレッドシートを作成
2. 以下のシートを作成：
   - `授業情報`: 授業科目名、担当教員名、メールアドレス
   - `欠席情報`: 提出日時、学生番号、氏名、欠席開始日、欠席終了日、欠席科目
3. スプレッドシートのIDを`Code.gs`の`SPREADSHEET_ID`に設定

### 4. Webアプリとしてデプロイ

1. 「デプロイ」→ 「新しいデプロイ」をクリック
2. 「種類の選択」で「ウェブアプリ」を選択
3. 以下の設定を行う：
   - 説明: 任意（例：「授業欠席連絡システム」）
   - 次のユーザーとして実行: 自分
   - アクセスできるユーザー: 全員
4. 「デプロイ」をクリック
5. 生成されたWebアプリのURLを保存

### 5. 権限の承認

初回実行時に以下の権限承認が必要です：
- Googleスプレッドシートの読み書き
- Gmail送信権限

## 使用方法

### 学生向け

1. 提供されたWebアプリのURLにアクセス
2. 以下の情報を入力：
   - 学生番号
   - 氏名
   - 欠席期間（開始日・終了日）
   - 欠席理由（任意）
   - 欠席する科目（複数選択可能）
3. 「欠席連絡を送信」ボタンをクリック
4. 送信完了メッセージで結果を確認

### 管理者向け

#### 授業情報の管理
1. Googleスプレッドシートの「授業情報」シートを開く
2. 新しい行に授業情報を追加：
   - A列：授業科目名
   - B列：担当教員名
   - C列：メールアドレス

#### 欠席記録の確認
1. 「欠席情報」シートで送信された欠席連絡を確認
2. 必要に応じてデータをフィルタリングや並び替え

## メール内容

送信されるメールには以下の情報が含まれます：

```
件名: 【欠席連絡】[科目名] - [学生名]さん

本文:
[教員名]先生

いつもお世話になっております。

以下の学生より授業の欠席連絡がありましたのでお知らせいたします。

【学生情報】
学生番号: [学生番号]
氏名: [学生名]

【欠席情報】
科目名: [科目名]
欠席期間: [開始日] ～ [終了日]

【欠席理由】
[欠席理由]

何かご不明な点がございましたら、学生に直接お問い合わせください。

よろしくお願いいたします。

---
このメールは授業欠席連絡システムから自動送信されました。
```

## トラブルシューティング

### よくある問題

**Q: 授業情報が表示されない**
A: スプレッドシートIDが正しく設定されているか、授業情報シートにデータが入力されているかを確認してください。

**Q: メールが送信されない**
A: 以下を確認してください：
- Gmail送信権限が承認されているか
- 教員のメールアドレスが正しく入力されているか
- 送信者のGoogleアカウントでGmailが有効になっているか

**Q: フォームにアクセスできない**
A: Webアプリのデプロイ設定で「アクセスできるユーザー」が「全員」になっているかを確認してください。

### ログの確認方法

1. Google Apps Scriptエディタを開く
2. 「実行数」→ 「実行」でログを確認
3. エラーが発生している場合は、エラーメッセージで原因を特定

## カスタマイズ

### メールテンプレートの変更
`sendAbsenceEmail`関数内の`subject`と`body`変数を編集してください。

### フォームデザインの変更
`form.html`内のCSS部分を編集してデザインをカスタマイズできます。

### バリデーションルールの追加
`form.html`の`validateForm`関数を編集して、追加の入力チェックを実装できます。
