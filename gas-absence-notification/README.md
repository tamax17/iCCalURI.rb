# 授業欠席連絡システム - Google Apps Script

学生が複数の授業を欠席する際に、各担当教員に一括でメール連絡を送信するWebアプリケーションです。

## 機能概要

- **学生向け機能**
  - Webフォームから欠席連絡を入力（学生情報・メールアドレス・欠席期間・理由・科目選択）
  - 複数科目の一括選択
  - 各担当教員への自動メール送信（返信先は学生のメールアドレス）
  - **スマートフォン完全対応**（レスポンシブデザイン・タッチ操作最適化）

- **管理者向け機能**
  - Googleスプレッドシートでの授業情報管理
  - 欠席記録の自動保存・管理
  - 管理者への即時通知メール（新しい欠席届提出時）
  - メール送信履歴の確認

## システム構成

### ファイル構成
```
gas-absence-notification/
├── Code.gs           # メインスクリプト
├── form.html         # 学生用入力フォーム
├── appsscript.json   # GASプロジェクト設定
└── README.md         # このファイル
```

### データ構造

#### 授業情報シート (`授業情報`)
| 列 | 項目名 | 説明 |
|---|---|---|
| A | 授業科目名 | 授業の名称 |
| B | 担当教員名 | 教員の氏名 |
| C | メールアドレス | 教員の連絡先メールアドレス |

#### 欠席情報シート (`欠席情報`)
| 列 | 項目名 | 説明 |
|---|---|---|
| A | 提出日時 | フォーム送信日時 |
| B | 学生番号 | 学生の識別番号 |
| C | 氏名 | 学生の氏名 |
| D | メールアドレス | 学生の連絡先メールアドレス |
| E | 欠席開始日 | 欠席期間の開始日 |
| F | 欠席終了日 | 欠席期間の終了日 |
| G | 欠席科目 | 欠席する科目（複数の場合はカンマ区切り） |

## セットアップ手順

### 1. Google Apps Scriptプロジェクトの作成

1. [Google Apps Script](https://script.google.com/) にアクセス
2. 「新しいプロジェクト」をクリック
3. プロジェクト名を「授業欠席連絡システム」に変更

### 2. ファイルのアップロード

1. `Code.gs`の内容を、デフォルトの`Code.gs`にコピー＆ペースト
2. `+`ボタン → `HTMLファイル`をクリックし、「form」という名前でHTMLファイルを作成
3. `form.html`の内容を上記ファイルにコピー＆ペースト
4. 歯車アイコン → `appsscript.json`の内容を更新

### 3. 設定の変更

#### 管理者メールアドレスの設定
1. `Code.gs`ファイルを開く
2. `ADMIN_EMAIL`の値を実際の管理者メールアドレスに変更
   ```javascript
   const ADMIN_EMAIL = 'your-admin@example.ac.jp';
   ```

### 4. スプレッドシートの準備

#### 自動作成の場合
1. `initializeSheets()`関数を実行
2. 実行ログに表示されるスプレッドシートIDをコピー
3. `Code.gs`の`SPREADSHEET_ID`をコピーしたIDに変更

#### 手動作成の場合
1. 新しいGoogleスプレッドシートを作成
2. 以下のシートを作成：
   - `授業情報`: 授業科目名、担当教員名、メールアドレス
   - `欠席情報`: 提出日時、学生番号、氏名、メールアドレス、欠席開始日、欠席終了日、欠席科目
3. スプレッドシートのIDを`Code.gs`の`SPREADSHEET_ID`に設定

### 5. Webアプリとしてデプロイ

1. 「デプロイ」→ 「新しいデプロイ」をクリック
2. 「種類の選択」で「ウェブアプリ」を選択
3. 以下の設定を行う：
   - 説明: 任意（例：「授業欠席連絡システム」）
   - 次のユーザーとして実行: 自分
   - アクセスできるユーザー: 全員
4. 「デプロイ」をクリック
5. 生成されたWebアプリのURLを保存

### 6. 権限の承認

初回実行時に以下の権限承認が必要です：
- Googleスプレッドシートの読み書き
- Gmail送信権限

## 使用方法

### 学生向け

1. 提供されたWebアプリのURLにアクセス
2. 以下の情報を入力：
   - 学生番号（例：B2024001 ※最初はアルファベット必須）
   - 氏名
   - メールアドレス（教員からの返信先として使用）
   - 欠席期間（開始日・終了日）
   - 欠席理由（任意）
   - 欠席する科目（複数選択可能）
3. 「欠席連絡を送信」ボタンをクリック
4. 送信完了メッセージで結果を確認

### 管理者向け

#### 授業情報の管理
1. Googleスプレッドシートの「授業情報」シートを開く
2. 新しい行に授業情報を追加：
   - A列：授業科目名
   - B列：担当教員名
   - C列：メールアドレス

#### 欠席記録の確認
1. 「欠席情報」シートで送信された欠席連絡を確認
2. 必要に応じてデータをフィルタリングや並び替え

## トラブルシューティング

### よくある問題

**Q: 授業情報が表示されない**
A: スプレッドシートIDが正しく設定されているか、授業情報シートにデータが入力されているかを確認してください。

**Q: メールが送信されない**
A: 以下を確認してください：
- Gmail送信権限が承認されているか
- 教員のメールアドレスが正しく入力されているか
- 送信者のGoogleアカウントでGmailが有効になっているか

**Q: フォームにアクセスできない**
A: Webアプリのデプロイ設定で「アクセスできるユーザー」が「全員」になっているかを確認してください。

### ログの確認方法

1. Google Apps Scriptエディタを開く
2. 「実行数」→ 「実行」でログを確認
3. エラーが発生している場合は、エラーメッセージで原因を特定

## スマートフォン対応

### 対応機能
- **レスポンシブデザイン**: 画面サイズに応じて自動的にレイアウトが調整
- **タッチ操作最適化**: チェックボックスやボタンのタップエリアを拡大
- **モバイルキーボード最適化**: 入力内容に応じて適切なキーボードを表示
- **iOS Safari対応**: viewportの問題やフォーカス時のスクロール問題を解決
- **パフォーマンス最適化**: スムーズなスクロールとタッチ応答

### モバイル向け最適化詳細

#### 入力フィールド
- 学生番号: 英数字入力（最初はアルファベット必須、自動大文字変換、リアルタイム検証）
- メールアドレス: メールキーボード表示  
- 氏名: 自動大文字化対応
- 日付: ネイティブ日付ピッカー使用
- 欠席理由: スペルチェック有効

#### レイアウト
- スマホ（576px以下）: 1カラムレイアウト
- タブレット（577px以上）: 2カラムレイアウト
- デスクトップ（768px以上）: フル機能レイアウト

#### タッチ操作
- ボタンの最小タッチサイズ: 48px
- チェックボックスエリア: 60px（ラベル全体がタッチ可能）
- 二重タップ防止機能搭載

### 推奨環境
- iOS Safari 12.0以上（ES5互換性対応済み）
- Android Chrome 80.0以上
- その他モダンブラウザ

### iOS Safari 対応状況
- ✅ ES5互換のJavaScript（アロー関数なし）
- ✅ webkit prefixによるCSS最適化
- ✅ iOS特有のviewport問題に対応
- ✅ タッチイベントの最適化
- ✅ 古いiOSバージョンでのフォールバック機能
- ✅ iframe制限回避システム
- ✅ 自動的な代替アクセス提案機能

### iOS Safari で開けない場合の解決方法

#### **方法1: 自動提案の利用**
1. iOS Safariでアクセス
2. 「iOS Safariをご使用の場合」の通知が表示
3. 「新しいタブで開く」ボタンをタップ

#### **方法2: Safari設定の変更**
1. iPhone「設定」→「Safari」
2. 「サイト越えトラッキングを防ぐ」→ オフ
3. 「すべてのCookieをブロック」→ オフ
4. Safari完全終了後、再アクセス

#### **方法3: 直接URLアクセス**
WebアプリURLの末尾に `?open_direct=1` を追加
```
例: https://script.google.com/macros/s/YOUR_ID/exec?open_direct=1
```

#### **方法4: 代替ブラウザの使用**
- iOS Chrome
- Firefox
- Edge
など他のブラウザを利用

## カスタマイズ

### メールテンプレートの変更
`sendAbsenceEmail`関数内の`subject`と`body`変数を編集してください。

`form.html`の`validateForm`関数を編集して、追加の入力チェックを実装できます。
